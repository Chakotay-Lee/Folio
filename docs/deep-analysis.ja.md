# 深度解析 使用ガイド

深度解析は、実行することで書籍の高度な機能を解放するオプションの AI 分析パイプラインです。深度解析を実行するまで、HTML エクスポート・TTS 音声・完全テキスト Book Chat などの機能は利用できません。

---

## 深度解析で解放される機能

| 機能 | 解析完了後の場所 |
|---|---|
| **章の要約** | 解析ページ → 章リスト |
| **抽出された図表** | 章の要約内に埋め込み表示 |
| **HTML エクスポート** | 解析ページ → Export HTML ボタン |
| **TTS 音声** | 解析ページ → 各章 → 再生ボタン |
| **完全テキスト Book Chat** | 書籍詳細パネル → Chat ボタン |

---

## 深度解析の起動方法

1. ライブラリから任意の書籍を開く
2. 書籍詳細パネルの**解析**ボタン（スパークルアイコン）をクリック
3. 確認ダイアログが表示されたら、オプションを調整できます
4. **深度解析**をクリックして開始

解析はバックグラウンドで実行されます。ページを離れて戻っても、進捗インジケーターは更新され続けます。

---

## 解析オプションの説明

### 出力言語
空欄のままにすると書籍の元の言語で出力されます。言語名（例：`English`、`繁體中文`、`日本語`）を入力すると、要約や図表説明を指定言語で生成します。

> これらの出力は AI が生成した個人的な読書補助であり、原著の翻訳ではありません。詳細は [法的事項](../README.ja.md#法的事項) をご参照ください。

### 追加プロンプト
AI による各章の読解・要約方法をカスタマイズできます。例：

| プロンプト | 効果 |
|---|---|
| `"小学生にもわかる言葉で各章を説明してください"` | 難解な内容をやさしく言い換え |
| `"各段落の末尾に「にゃん」をつけて、猫の口調で解説してください"` | ユニークな語り口で記憶に残る読書体験 |
| `"各章の核心を日常のたとえ話ひとつで説明してください"` | 比喩による深い理解 |
| `"各章のポイントを箇条書き3つにまとめてください。余分な説明は不要です"` | 素早い復習のための要点整理 |

### ページ範囲
書籍の指定ページ範囲のみを解析します。以下の用途に適しています：
- 本格実行前に少ない範囲で設定をテストする
- 特定の章だけ解析したい場合

### モード
| モード | 説明 |
|---|---|
| **Full（完全）** | 全パイプライン：OCR・図表抽出・要約・HTML エクスポート |
| **Quick（高速）** | 要約のみ生成、図表抽出をスキップ；高速かつトークン消費が少ない |

---

## トークン消費の目安

深度解析のトークン消費は通常のインデックス作成より大幅に多くなります。クラウド API の費用にご注意ください：

| ステージ | おおよそのトークン数 |
|---|---|
| OCR（スキャンページ） | 1ページあたり約 1,000〜3,000（画像トークン含む） |
| 章の要約 | 1章あたり約 2,000〜5,000 |
| 図表の説明 | 1枚あたり約 500〜1,500 |

10章・図表30枚の300ページスキャン書籍では、クラウドモデル使用時に **50万〜100万トークン以上** を消費することがあります。

**推奨事項：**
- まず **Quick モード**で結果を確認してから Full を実行する
- **[Ollama](https://ollama.ai) のローカルモデル**を使用してクラウドコストをゼロにする
- **ページ範囲**で少ページのテストを行い、効果を確認してから全体を解析する

---

## 再解析について

書籍の深度解析はいつでも再実行できます。既存の解析結果（要約・音声キャッシュ・HTML）が上書きされるため、確認の警告が表示されます。

---

## 推奨モデル

図表抽出とスキャン PDF の OCR には**ビジョン対応（マルチモーダル）モデル**が必要です。

| 用途 | 推奨 |
|---|---|
| 総合的に最良 | **Qwen2-VL / Qwen3**（Ollama 経由） |
| クラウド・コスト重視 | Gemini 2.5 Flash |
| テキストのみ PDF（図表なし） | 能力十分な任意のテキストモデル |

---

## 出力ファイルの場所

すべての解析データはライブラリデータディレクトリ内の `analysis/{book-uuid}/` に保存されます：

| パス | 内容 |
|---|---|
| `text/ch_NN.txt` | 章ごとの完全抽出テキスト |
| `text/ch_NN_summary.txt` | 章の要約（TTS・Book Chat で使用） |
| `figures/` | 抽出された図表画像 |
| `audio/` | キャッシュされた TTS 音声ファイル |
| `book.html` | 自己完結型 HTML エクスポートファイル |
