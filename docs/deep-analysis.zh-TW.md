# 深度解析使用指南

深度解析是一個選配的 AI 分析管道，執行後才能解鎖書籍的進階功能。在執行深度解析之前，HTML 匯出、TTS 語音、完整內文 Book Chat 等功能均不可用。

---

## 深度解析解鎖的功能

| 功能 | 分析完成後在哪裡找 |
|---|---|
| **章節摘要** | 分析頁面 → 章節清單 |
| **擷取的圖表** | 內嵌於章節摘要中 |
| **HTML 匯出** | 分析頁面 → Export HTML 按鈕 |
| **TTS 語音** | 分析頁面 → 各章節 → 播放按鈕 |
| **完整內文 Book Chat** | 書籍詳細面板 → Chat 按鈕 |

---

## 如何觸發深度解析

1. 在書庫中開啟任意一本書
2. 點擊書籍詳細面板中的**分析**按鈕（星火圖示）
3. 確認對話框出現後，可在此調整分析選項
4. 點擊**深度解析**開始執行

分析在背景執行，可以離開頁面再回來，進度指示器會持續更新。

---

## 分析選項說明

### 輸出語言
留空則以書籍原文語言輸出。填入語言名稱（例如 `English`、`繁體中文`、`日本語`）可讓摘要和圖表描述以指定語言產生。

> 這些輸出是 AI 產生的個人閱讀輔助，並非原著翻譯。詳見 [法律聲明](../README.zh-TW.md#法律聲明)。

### 額外提示詞
自訂 AI 解讀和摘要每一章的方式。範例：

| 提示詞 | 效果 |
|---|---|
| `"用小學生也能懂的方式解說每一章"` | 語言簡化，適合快速掌握陌生領域 |
| `"每段結尾加「喵」，用貓咪的口吻解說"` | 趣味呈現，幫助記憶枯燥內容 |
| `"用一個生活中的比喻來說明每章的核心概念"` | 以類比加深理解 |
| `"每章給我 3 條重點，不要廢話"` | 快速複習用的精煉摘要 |

### 頁碼範圍
只分析書籍的指定頁碼區間，適用於：
- 正式執行前先用小範圍測試設定
- 只需要分析特定章節的情況

### 模式
| 模式 | 說明 |
|---|---|
| **Full（完整）** | 完整管道：OCR、圖表擷取、摘要、HTML 匯出 |
| **Quick（快速）** | 僅產生摘要，跳過圖表擷取；速度更快，Token 消耗更少 |

## Token 消耗估算

深度解析的 Token 消耗遠高於一般書籍匯入，請注意雲端 API 費用：

| 階段 | 概估 Token 用量 |
|---|---|
| OCR（掃描頁面） | 每頁約 1,000–3,000（含圖片 token） |
| 章節摘要 | 每章約 2,000–5,000 |
| 圖表描述 | 每張圖約 500–1,500 |

一本 300 頁的掃描版書籍，含 10 章、30 張圖，使用雲端模型時可能消耗 **50 萬至 100 萬以上 Token**。

**建議：**
- 先用 **Quick 模式**確認結果，再視需要執行 Full
- 使用 **[Ollama](https://ollama.ai) 本地模型**完全避免雲端費用
- 先以**頁碼範圍**對少數頁面測試，確認效果後再全書分析

---

## 重新執行分析

可隨時對書籍重新執行深度解析。系統會顯示確認警告，因為現有的分析結果（摘要、音訊快取、HTML）將被覆蓋。

---

## 推薦模型

圖表擷取和掃描 PDF 的 OCR 需要**支援視覺輸入的多模態模型**。

| 使用情境 | 推薦 |
|---|---|
| 整體最佳 | **Qwen2-VL / Qwen3**（透過 Ollama） |
| 雲端、注重費用 | Gemini 2.5 Flash |
| 純文字 PDF（無圖表） | 任何能力足夠的文字模型 |

---

## 輸出檔案位置

所有分析資料儲存於書庫資料目錄下的 `analysis/{book-uuid}/`：

| 路徑 | 內容 |
|---|---|
| `text/ch_NN.txt` | 每章完整提取文字 |
| `text/ch_NN_summary.txt` | 章節摘要（供 TTS 和 Book Chat 使用） |
| `figures/` | 擷取的圖表圖片 |
| `audio/` | 快取的 TTS 音訊檔案 |
| `book.html` | 自含式 HTML 匯出檔案 |
