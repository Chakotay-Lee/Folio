# 深度解析使用指南

深度解析是一个可选的 AI 分析流程，执行后才能解锁书籍的高级功能。在执行深度解析之前，HTML 导出、TTS 语音、完整内文 Book Chat 等功能均不可用。

---

## 深度解析解锁的功能

| 功能 | 分析完成后在哪里找 |
|---|---|
| **章节摘要** | 分析页面 → 章节列表 |
| **提取的图表** | 内嵌于章节摘要中 |
| **HTML 导出** | 分析页面 → Export HTML 按钮 |
| **TTS 语音** | 分析页面 → 各章节 → 播放按钮 |
| **完整内文 Book Chat** | 书籍详情面板 → Chat 按钮 |

---

## 如何触发深度解析

1. 在书库中打开任意一本书
2. 点击书籍详情面板中的**分析**按钮（星火图标）
3. 确认对话框出现后，可在此调整分析选项
4. 点击**深度解析**开始执行

分析在后台运行，可以离开页面再返回，进度指示器会持续更新。

---

## 分析选项说明

### 输出语言
留空则以书籍原文语言输出。填入语言名称（例如 `English`、`繁體中文`、`日本語`）可让摘要和图表描述以指定语言生成。

> 这些输出是 AI 生成的个人阅读辅助，并非原著翻译。详见 [法律声明](../README.zh-CN.md#法律声明)。

### 额外提示词
自定义 AI 解读和摘要每一章的方式。示例：

| 提示词 | 效果 |
|---|---|
| `"用小学生也能理解的方式解说每一章"` | 语言简化，适合快速掌握陌生领域 |
| `"每段结尾加「喵」，用猫咪的口吻解说"` | 趣味呈现，帮助记忆枯燥内容 |
| `"用一个生活中的比喻来说明每章的核心概念"` | 以类比加深理解 |
| `"每章给我 3 条重点，不要废话"` | 快速复习用的精炼摘要 |

### 页码范围
只分析书籍的指定页码区间，适用于：
- 正式执行前先用小范围测试设置
- 只需要分析特定章节的情况

### 模式
| 模式 | 说明 |
|---|---|
| **Full（完整）** | 完整流程：OCR、图表提取、摘要、HTML 导出 |
| **Quick（快速）** | 仅生成摘要，跳过图表提取；速度更快，Token 消耗更少 |

---

## Token 消耗估算

深度解析的 Token 消耗远高于一般书籍导入，请注意云端 API 费用：

| 阶段 | 概估 Token 用量 |
|---|---|
| OCR（扫描页面） | 每页约 1,000–3,000（含图片 token） |
| 章节摘要 | 每章约 2,000–5,000 |
| 图表描述 | 每张图约 500–1,500 |

一本 300 页的扫描版书籍，含 10 章、30 张图，使用云端模型时可能消耗 **50 万至 100 万以上 Token**。

**建议：**
- 先用 **Quick 模式**确认结果，再视需要执行 Full
- 使用 **[Ollama](https://ollama.ai) 本地模型**完全避免云端费用
- 先以**页码范围**对少数页面测试，确认效果后再全书分析

---

## 重新执行分析

可随时对书籍重新执行深度解析。系统会显示确认警告，因为现有的分析结果（摘要、音频缓存、HTML）将被覆盖。

---

## 推荐模型

图表提取和扫描 PDF 的 OCR 需要**支持视觉输入的多模态模型**。

| 使用场景 | 推荐 |
|---|---|
| 整体最佳 | **Qwen2-VL / Qwen3**（通过 Ollama） |
| 云端、注重费用 | Gemini 2.5 Flash |
| 纯文字 PDF（无图表） | 任何能力足够的文字模型 |

---

## 输出文件位置

所有分析数据存储于书库数据目录下的 `analysis/{book-uuid}/`：

| 路径 | 内容 |
|---|---|
| `text/ch_NN.txt` | 每章完整提取文字 |
| `text/ch_NN_summary.txt` | 章节摘要（供 TTS 和 Book Chat 使用） |
| `figures/` | 提取的图表图片 |
| `audio/` | 缓存的 TTS 音频文件 |
| `book.html` | 独立 HTML 导出文件 |
